## 1. Скільки коштує порядок полів

Ті самі три поля, лише в іншому порядку, займають різну кількість пам'яті.

```cpp
#include <cstdint>
#include <iostream>
struct Wasteful {
    char a;
    int b;
    char c;
};
struct Tidy {
    int b;
    char a;
    char c;
};
int main() {
    std::cout << sizeof(Wasteful) << ' ' << sizeof(Tidy) << '\n';
}
```

**Вгадайте:** два числа.

**Зміни одне:** додайте в `Tidy` ще два поля `char d; char e;`. Потім натомість замініть у `Tidy` `int b` на `double b`.

**Що це означає:** компілятор вирівнює поля й додає вирівнювальні байти ([теорія §1](lab-06-named-bundles.md#1-struct--це-поля-поруч-у-яких-є-імена)).

## 2. Звичайний enum і enum class

Звичайний `enum` тихо перетворюється на число. `enum class` — ні.

```cpp
#include <cstdint>
#include <iostream>
enum Color { Red, Green, Blue };
int main() {
    Color c = Green;
    int x = c + 10;
    std::cout << x << '\n';
}
```

**Вгадайте:** одне число.

**Зміни одне:** замініть `enum` на `enum class`. Виправте, що скаже компілятор, і зберіть ще раз.

**Що це означає:** `enum class` не змішується з `int` без явного приведення ([теорія §2](lab-06-named-bundles.md#2-enum-class--це-типізований-набір-цілих)).

## 3. Структура копіюється цілком

Звичайний масив не можна присвоїти іншому. А масив усередині структури — копіюється разом із нею.

```cpp
#include <cstdint>
#include <iostream>
struct Sprite {
    int x, y;
    int trail[3];
};
int main() {
    Sprite a = {1, 2, {7, 8, 9}};
    Sprite b = a;
    b.x = 100;
    b.trail[0] = 0;
    std::cout << a.x << ' ' << a.trail[0] << '\n';
    std::cout << b.x << ' ' << b.trail[0] << '\n';
}
```

**Вгадайте:** два рядки по два числа.

**Зміни одне:** подумайте: що надрукував би перший рядок, якби `b` була не копією, а посиланням `Sprite& b = a;`?

**Що це означає:** присвоєння структури копіює всі поля, разом із масивом ([теорія §1](lab-06-named-bundles.md#1-struct--це-поля-поруч-у-яких-є-імена)).

## 4. Вісім кнопок по байту

У Пісочниці 02 вісім кнопок жили в одному байті. А якщо кожній дати свій `bool`?

```cpp
#include <cstdint>
#include <iostream>
struct Buttons {
    bool up, down, left, right, a, b, start, select;
};
int main() {
    std::cout << sizeof(Buttons) << ' ' << sizeof(std::uint8_t) << '\n';
    Buttons many[100] = {};
    std::cout << sizeof(many) << '\n';
}
```

**Вгадайте:** два числа в першому рядку й одне в другому.

**Зміни одне:** подумайте: скільки байтів займали б ті самі 100 наборів кнопок, якби кожен був одним `std::uint8_t` з бітами?

**Що це означає:** `bool` займає цілий байт, а бітове поле — біт ([теорія §1](lab-06-named-bundles.md#1-struct--це-поля-поруч-у-яких-є-імена)).

## 5. Адреса змінної, якої вже немає

Функція повертає адресу своєї локальної змінної. Що там лежатиме після повернення?

```cpp
#include <cstdint>
#include <iostream>
int* make() {
    int local = 42;
    return &local;
}
int main() {
    int* p = make();
    std::cout << *p << '\n';
}
```

**Вгадайте:** що надрукує програма? Потім зберіть.

**Зміни одне:** подумайте: чому з `static int local = 42;` усе було б гаразд?

**Що це означає:** автоматична змінна зникає разом із кадром функції ([теорія §3](lab-06-named-bundles.md#3-три-часи-життя)).

## 6. Читання після delete

Об'єкт звільнено, а вказівник на нього лишився.

```cpp
#include <cstdint>
#include <iostream>
struct Point {
    int x, y;
};
int main() {
    Point* p = new Point{3, 4};
    std::cout << p->x + p->y << '\n';
    delete p;
    std::cout << p->x << '\n';
}
```

**Вгадайте:** що надрукує програма і що скаже санітайзер?

**Зміни одне:** одразу після `delete p;` допишіть `p = nullptr;`.

**Що це означає:** завислий вказівник — це вказівник, у якого не лишилось об'єкта ([теорія §3](lab-06-named-bundles.md#3-три-часи-життя)).

## 7. Два байти, одне число

16-бітне число — це два байти. Покладіть їх у структуру з двох полів і подивіться, котрий куди ліг.

```cpp
#include <cstdint>
#include <cstring>
#include <iostream>
struct Pair {
    std::uint8_t lo;
    std::uint8_t hi;
};
int main() {
    std::uint16_t value = 0x1234;
    Pair p;
    std::memcpy(&p, &value, sizeof(p));
    std::cout << std::hex << (int)p.lo << ' ' << (int)p.hi << '\n';
}
```

**Вгадайте:** два шістнадцяткові числа.

**Зміни одне:** візьміть `value = 300`.

**Що це означає:** поля структури лежать у пам'яті по порядку, а число — молодшим байтом уперед ([теорія §1](lab-06-named-bundles.md#1-struct--це-поля-поруч-у-яких-є-імена)).
