## 1. Факторіал, що не вліз

13! — це понад шість мільярдів. А скільки влазить в `int`?

```cpp
#include <cstdint>
#include <iostream>
int fact(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * fact(n - 1);
}
int main() {
    for (int n = 10; n <= 13; ++n) {
        std::cout << n << "! = " << fact(n) << '\n';
    }
}
```

**Вгадайте:** чотири рядки. На якому з них щось піде не так?

**Зміни одне:** замініть тип повернення `int fact` на `long long fact`.

**Що це означає:** рекурсія працює, але результат має тип, і тип має розмір ([теорія §3](lab-07-call-and-return.md#3-рекурсії-потрібні-базовий-випадок-і-менший-випадок)).

## 2. Скільки разів рахує Фібоначчі

Наївний рекурсивний Фібоначчі рахує те саме знову і знову.

```cpp
#include <cstdint>
#include <iostream>
int calls = 0;
int fib(int n) {
    calls = calls + 1;
    if (n < 2) {
        return n;
    }
    return fib(n - 1) + fib(n - 2);
}
int main() {
    std::cout << fib(10) << ' ' << calls << '\n';
}
```

**Вгадайте:** `fib(10)` і скільки разів викликалась функція.

**Зміни одне:** порахуйте `fib(20)`.

**Що це означає:** кожен виклик робить ще два, і дерево викликів росте дуже швидко ([теорія §3](lab-07-call-and-return.md#3-рекурсії-потрібні-базовий-випадок-і-менший-випадок)).

## 3. Три способи передати

Копія, вказівник і посилання — що з них змінить змінну того, хто викликав?

```cpp
#include <cstdint>
#include <iostream>
void by_value(int x) { x = x + 1; }
void by_pointer(int* x) { *x = *x + 1; }
void by_reference(int& x) { x = x + 1; }
int main() {
    int a = 10;
    by_value(a);
    std::cout << a << '\n';
    by_pointer(&a);
    std::cout << a << '\n';
    by_reference(a);
    std::cout << a << '\n';
}
```

**Вгадайте:** три числа.

**Зміни одне:** подумайте: що буде, якщо в `main` викликати `by_value(a)` ще десять разів?

**Що це означає:** копія живе у своєму кадрі, а вказівник і посилання ведуть до оригіналу ([теорія §2](lab-07-call-and-return.md#2-як-значення-потрапляють-усередину-й-назовні)).

## 4. Рекурсія без кінця

Базовий випадок тут є, але він ніколи не спрацює.

```cpp
#include <cstdint>
#include <iostream>
int depth(int n) {
    if (n < 0) {
        return 0;
    }
    return 1 + depth(n + 1);
}
int main() {
    std::cout << depth(0) << '\n';
}
```

**Вгадайте:** що надрукує програма?

**Зміни одне:** умову замініть на `n > 1000`.

**Що це означає:** без досяжного базового випадку стек переповнюється ([теорія §3](lab-07-call-and-return.md#3-рекурсії-потрібні-базовий-випадок-і-менший-випадок)).

## 5. Вниз і вгору

Кожен виклик має свій кадр, і друк після рекурсивного виклику чекає, поки той повернеться.

```cpp
#include <cstdint>
#include <iostream>
void count(int n) {
    if (n == 0) {
        return;
    }
    std::cout << "вниз " << n << '\n';
    count(n - 1);
    std::cout << "вгору " << n << '\n';
}
int main() {
    count(3);
}
```

**Вгадайте:** шість рядків по порядку.

**Зміни одне:** поміняйте місцями рядок `std::cout << "вниз "…` і рядок `count(n - 1);`.

**Що це означає:** у кожного виклику свій кадр і своє `n`, і вони повертаються в зворотному порядку ([теорія §1](lab-07-call-and-return.md#1-виклик--це-стрибок-який-памятає)).

## 6. Яку функцію обере компілятор

Три функції з однаковим іменем. Котру з них викличе кожен рядок?

```cpp
#include <cstdint>
#include <iostream>
void show(int x)    { std::cout << "int " << x << '\n'; }
void show(double x) { std::cout << "double " << x << '\n'; }
void show(char x)   { std::cout << "char " << x << '\n'; }
int main() {
    show(65);
    show(65.0);
    show('A');
    show('A' + 1);
}
```

**Вгадайте:** чотири рядки.

**Зміни одне:** подумайте: що надрукує `show('A' + 'B')`?

**Що це означає:** перевантаження розв'язується на етапі компіляції за типом аргументу ([теорія §2](lab-07-call-and-return.md#2-як-значення-потрапляють-усередину-й-назовні)).

## 7. Ханойські вежі

За легендою, ченці переносять 64 золоті диски, і коли закінчать — настане кінець світу.

```cpp
#include <cstdint>
#include <iostream>
int moves = 0;
void hanoi(int n, char from, char to, char via) {
    if (n == 0) {
        return;
    }
    hanoi(n - 1, from, via, to);
    moves = moves + 1;
    hanoi(n - 1, via, to, from);
}
int main() {
    hanoi(3, 'A', 'C', 'B');
    std::cout << moves << '\n';
}
```

**Вгадайте:** скільки ходів для трьох дисків?

**Зміни одне:** візьміть 10 дисків.

**Що це означає:** задача зводиться до двох менших того самого виду — це і є рекурсія ([теорія §3](lab-07-call-and-return.md#3-рекурсії-потрібні-базовий-випадок-і-менший-випадок)).
