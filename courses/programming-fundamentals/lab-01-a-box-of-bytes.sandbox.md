## 1. Лічильник, що обнуляється

GPS-супутники передають номер тижня в десяти бітах, тобто від 0 до 1023. У серпні
1999 і у квітні 2019 року лічильник дійшов до кінця й почав з нуля, і приймачі,
які цього не чекали, показали дату двадцятирічної давнини.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    std::uint8_t trip = 0;                    // лічильник на один байт
    for (int km = 0; km < 300; ++km) {
        trip = (std::uint8_t)(trip + 1);
    }
    std::cout << (int)trip << '\n';

    int week = 1023;                          // номер тижня GPS: 0..1023
    week = (week + 1) % 1024;
    std::cout << week << '\n';
}
```

**Вгадайте:** що надрукує кожен рядок?

**Зміни одне:** почніть з `trip = 0` і відніміть одиницю один раз. Що буде?

### Напишіть самі

Лічильник пробігу тепер на два байти, `std::uint16_t`, і стоїть на 65000. Напишіть
програму, яка крутить його по кілометру, поки він знову не покаже 0, і друкує,
скільки кілометрів на це пішло.

Має надрукуватись: `536`

**Що це означає:** беззнакове число загортається за модулем 2ⁿ, і мова це обіцяє
([теорія §3](lab-01-a-box-of-bytes.md#3-переповнення-рухома-кома-й-інша-брехня)).
Таймери в мікроконтролерах загортаються так постійно — [у залізі](HARDWARE.md#lab-1--коробка-байтів).

## 2. Сто годин по одній десятій

У 1991 році система протиракетної оборони Patriot рахувала час десятими частками
секунди. Після ста годин роботи похибка виросла настільки, що система не змогла
супроводити ціль.

### Передбачте

```cpp
#include <iostream>
int main() {
    float seconds = 0.0f;
    for (int tick = 0; tick < 3600000; ++tick) {   // 100 годин по 0.1 секунди
        seconds = seconds + 0.1f;
    }
    std::cout << seconds << '\n';

    int tenths = 0;
    for (int tick = 0; tick < 3600000; ++tick) {
        tenths = tenths + 1;
    }
    std::cout << tenths / 10.0 << '\n';
}
```

**Вгадайте:** чи будуть обидва рядки 360000? Якщо ні, який із них більший?

**Зміни одне:** замініть `float` на `double`, а `0.0f` і `0.1f` — на `0.0` і `0.1`.
Тепер обидва рядки однакові? Потім додайте `#include <iomanip>` і друкуйте
`std::cout << std::setprecision(15) << seconds`. Що видно тепер?

### Напишіть самі

Годинник, який не бреше: рахуйте час лише в цілих десятих частках секунди. Напишіть
функцію `void show(int tenths)`, яка друкує час як `години:хвилини:секунди`, з двома
цифрами для хвилин і секунд. Для хвилин і секунд знадобляться `/` і `%`, а для
нуля попереду — `std::setw(2)` і `std::setfill('0')` з `<iomanip>`.

Для `show(3600000)` і `show(12345)` має надрукуватись:

```txt
100:00:00
0:20:34
```

**Що це означає:** `0.1` у двійковому записі неточне, і похибка накопичується з кожним
додаванням ([теорія §3](lab-01-a-box-of-bytes.md#3-переповнення-рухома-кома-й-інша-брехня)).
Цілі десяті частки — точні, тому час у пристроях зазвичай рахують цілими.

## 3. HAL і IBM

Комп'ютер у фільмі «Космічна одіссея 2001 року» звуть HAL. Зсуньте кожну літеру на
одну вперед і подивіться, що вийде.

### Передбачте

```cpp
#include <iostream>
int main() {
    char word[] = "HAL";
    for (int i = 0; word[i] != '\0'; ++i) {
        word[i] = (char)(word[i] + 1);
    }
    std::cout << word << '\n';
    std::cout << 'a' - 'A' << '\n';
}
```

**Вгадайте:** слово в першому рядку й число в другому.

**Зміни одне:** візьміть `char word[] = "hello world";` і замість `+ 1` відніміть 32.
Що надрукується і чому не все речення?

### Напишіть самі

Виправте той баг. Напишіть функцію `void to_upper(char* s)`, яка робить великими
лише літери від `a` до `z`, а пробіли, цифри й інші символи лишає як є.

Для рядків `"hello world 2"` і `"HAL 9000"` має надрукуватись:

```txt
HELLO WORLD 2
HAL 9000
```

**Що це означає:** символ — це число, і з ним можна рахувати
([теорія §4](lab-01-a-box-of-bytes.md#4-символ--це-число-в-костюмі)). А рядок
закінчується там, де трапився нульовий байт, навіть якщо ви цього не планували.

## 4. Формула, яка завжди дає нуль

Перевести градуси Фаренгейта в Цельсія — шкільна формула: `(f − 32) · 5 / 9`.

### Передбачте

```cpp
#include <iostream>
int main() {
    int f = 100;
    int c1 = (f - 32) * 5 / 9;
    int c2 = 5 / 9 * (f - 32);
    double c3 = (f - 32) * 5.0 / 9;
    std::cout << c1 << ' ' << c2 << ' ' << c3 << '\n';
}
```

**Вгадайте:** три числа. Математично `c1` і `c2` — те саме.

**Зміни одне:** `f = 0`. Що тепер покаже `c1`: −18 чи −17?

### Напишіть самі

Напишіть функцію `int celsius(int f)`, яка округлює до **найближчого** цілого, а не
відкидає дріб. Порахуйте в `double`, а округліть через `std::lround` з `<cmath>`.

Для `celsius(100)`, `celsius(0)` і `celsius(212)` має надрукуватись: `38 -18 100`

**Що це означає:** цілочисельне ділення відкидає дріб, і порядок дій вирішує, коли
саме це станеться ([теорія §2](lab-01-a-box-of-bytes.md#2-тип--це-розмір-і-набір-операцій)).
Відкидає воно в бік нуля, а не вниз.

## 5. Швидкість, що не влізла

У 1996 році ракета Ariane 5 зруйнувалась на 37-й секунді польоту: швидкість, яку
рахували в 64 бітах, записали в 16-бітне знакове ціле, а вона туди не влізла.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int speeds[] = {30000, 32767, 32768, 40000, 65536};
    for (int i = 0; i < 5; ++i) {
        std::int16_t stored = (std::int16_t)speeds[i];
        std::cout << speeds[i] << " -> " << stored << '\n';
    }
}
```

**Вгадайте:** що стоятиме праворуч від стрілки в кожному з п'яти рядків?

**Зміни одне:** замініть обидва `std::int16_t` на `std::uint16_t`. Які рядки
змінились?

### Напишіть самі

Зробіть так, як роблять у пристроях, щоб не повторити Ariane: **насичення**. Напишіть
функцію `std::int16_t saturate(int v)`, яка повертає 32767 для всього, що більше,
−32768 для всього, що менше, а решту — як є.

Для `saturate(40000)`, `saturate(-40000)` і `saturate(100)` має надрукуватись:
`32767 -32768 100`

**Що це означає:** тип — це розмір. У 16 знакових бітах живуть числа від −32768 до
32767, а все більше читається з тих самих бітів як інше число
([теорія §2](lab-01-a-box-of-bytes.md#2-тип--це-розмір-і-набір-операцій)). Чому саме
таке — розповість Lab 2.

## 6. Хто спіймає помилку

У кожному фрагменті є помилка. Хто її спіймає: **(А)** компілятор відмовиться
перекладати, **(Б)** компілятор попередить, а `-Werror` зробить з попередження
помилку, **(В)** санітайзер під час виконання чи **(Г)** ніхто?

### Передбачте

Кожен фрагмент вставте всередину `int main() { … }` з `#include <iostream>`.

| # | Фрагмент |
|---|---|
| 1 | `int x = 5` (без крапки з комою), далі `std::cout << x << '\n';` |
| 2 | `int x;` далі `std::cout << x << '\n';` |
| 3 | `int big = 2147483647;` `big = big + 1;` `std::cout << big << '\n';` |
| 4 | `int a[3] = {1, 2, 3};` `int i = 3;` `std::cout << a[i] << '\n';` |
| 5 | `unsigned char c = 300;` `std::cout << (int)c << '\n';` |
| 6 | `double d = 0.1 + 0.2;` і `if (d == 0.3)` друкує `equal`, інакше `not equal` |

**Вгадайте:** літеру для кожного рядка. Потім зберіть кожен фрагмент і перевірте.

**Зміни одне:** у фрагменті 4 замініть `a[i]` на `a[3]`. Хто спіймає тепер?

### Напишіть самі

Виправте всі шість фрагментів і зберіть їх в одну програму, яка збирається без
попереджень, а санітайзер мовчить. Для фрагмента 3 візьміть ширший тип, для 4 —
останній дозволений індекс, для 5 — тип, у який 300 влазить, а для 6 порівнюйте
не `==`, а різницю з допуском (`std::fabs` з `<cmath>`).

Має надрукуватись:

```txt
5
0
2147483648
3
300
equal
```

**Що це означає:** помилка може спіймати себе на трьох рівнях — або не спіймати
зовсім ([теорія §1](lab-01-a-box-of-bytes.md#1-виконується-не-той-текст-який-ви-написали)).
Що означають самі повідомлення — в [errors.notes.md](errors.notes.md).
