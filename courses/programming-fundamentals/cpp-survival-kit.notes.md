## 1. Скелет

Найкоротша програма на C++, яка щось робить:

```cpp
#include <iostream>

int main() {
    std::cout << "hello\n";
    return 0;
}
```

**Очікуй:** `hello`.

- `#include <iostream>` — «дай мені засоби введення-виведення». Без цього `std::cout` не існує.
- `int main()` — функція, з якої починається програма. Її викликає операційна система.
- `std::cout << x` — «надрукуй `x`». Стрілки показують напрям: значення тече у вивід.
- `"\n"` — перехід на новий рядок. Без нього все злипнеться в один.
- `return 0;` — «все добре». Ненульове число означало б помилку.
- Крапка з комою в кінці **кожної** команди. Це №1 серед помилок новачка.

Друкувати можна кілька речей підряд:

```cpp
std::cout << "answer is " << 42 << '\n';
```

`std::` — це «зі стандартної бібліотеки». Пишемо повністю, без `using namespace std;` — так видно, що звідки.

## 2. Змінні

Змінна — ім'я для значення в пам'яті. У C++ ім'я має **тип**.

```cpp
#include <iostream>

int main() {
    int    count = 3;       // ціле число
    double ratio = 0.5;     // дробове
    char   letter = 'A';    // один символ
    bool   ready = true;    // так / ні

    count = count + 1;      // присвоєння: правий бік рахуємо, кладемо в лівий

    std::cout << count << ' ' << ratio << ' ' << letter << ' ' << ready << '\n';
    return 0;
}
```

**Очікуй:** `4 0.5 A 1`. `bool` друкується як `1`/`0`, не як `true`/`false`.

Три правила на перший тиждень:

- **Завжди ініціалізуйте.** `int x;` без значення — сміття в пам'яті, читати його не можна.
- `=` це присвоєння, `==` це порівняння. Плутанина між ними — окрема тема в [Lab 4](lab-04-the-shape-of-control.md).
- `'A'` (одинарні лапки) — один символ. `"A"` (подвійні) — текст. Це різні речі.

Про те, чому `int` саме такий і що буде після 255 — уся [Lab 1](lab-01-a-box-of-bytes.md).

## 3. `if` — розгалуження

```cpp
#include <iostream>

int main() {
    int x = 7;

    if (x > 10) {
        std::cout << "big\n";
    } else if (x > 5) {
        std::cout << "medium\n";
    } else {
        std::cout << "small\n";
    }
    return 0;
}
```

**Очікуй:** `medium`. Перевірки йдуть згори вниз, спрацьовує **перша** істинна, решта пропускаються.

Порівняння: `==` дорівнює, `!=` не дорівнює, `<` `>` `<=` `>=`.
Склеювання умов: `&&` (і), `||` (або), `!` (не).

```cpp
if (x > 0 && x < 100) { /* ... */ }
```

Фігурні дужки ставте **завжди**, навіть на один рядок. Це не естетика — це найдешевший спосіб не отримати баг, коли завтра допишете другий рядок.

## 4. `while` і `for` — повторення

`while` повторює, **поки** умова істинна:

```cpp
#include <iostream>

int main() {
    int i = 0;
    while (i < 3) {
        std::cout << i << '\n';
        i = i + 1;          // без цього рядка цикл ніколи не закінчиться
    }
    return 0;
}
```

**Очікуй:** `0`, `1`, `2` — три рядки.

`for` — той самий цикл, але лічильник, умова й крок зібрані в одному місці:

```cpp
for (int i = 0; i < 3; ++i) {
    std::cout << i << '\n';
}
```

Читається так: «створи `i = 0`; поки `i < 3`; після кожного проходу `++i`».
`++i` це `i = i + 1`, лише коротше.

Цикл у циклі — рядки й колонки таблиці:

```cpp
for (int row = 0; row < 2; ++row) {
    for (int col = 0; col < 3; ++col) {
        std::cout << row << col << ' ';
    }
    std::cout << '\n';
}
```

**Очікуй:**

```txt
00 01 02
10 11 12
```

Внутрішній цикл повністю прокручується на **кожному** кроці зовнішнього. Саме так влаштований `dump` у скелеті: зовнішній цикл — рядки по 16 байтів, внутрішній — байти в рядку.

`while (true)` — нескінченний цикл; виходять з нього через `break`. Prompt у `main.cpp` саме такий.

## 5. Функція — шматок коду з іменем

```cpp
#include <iostream>
#include <string>

// тип результату, ім'я, параметри в дужках
int doubled(int x) {
    return x * 2;
}

void greet(const std::string& name) {   // void = нічого не повертає
    std::cout << "hi, " << name << '\n';
}

int main() {
    std::cout << doubled(21) << '\n';
    greet("ember");
    return 0;
}
```

**Очікуй:** `42`, потім `hi, ember`.

- Функція має бути **оголошена вище** місця, де її викликають — або в заголовку `.hpp`, як у скелеті.
- `return` віддає значення й одразу виходить із функції.
- Параметр — це **копія**. Змінили `x` усередині — зовні нічого не сталось. Чому так і як обійти — [Lab 3](lab-03-addresses-not-names.md) і [Lab 7](lab-07-call-and-return.md).

## 6. Масив — багато значень під одним іменем

```cpp
#include <iostream>

int main() {
    int a[4] = {10, 20, 30, 40};

    std::cout << a[0] << ' ' << a[3] << '\n';

    for (int i = 0; i < 4; ++i) {
        std::cout << a[i] << ' ';
    }
    std::cout << '\n';
    return 0;
}
```

**Очікуй:** `10 40`, потім `10 20 30 40`.

Нумерація **з нуля**: у масиві на 4 елементи індекси `0 1 2 3`. `a[4]` вже за межами — це помилка, яку ловить санітайзер. Пам'ять `ember` — такий самий масив, тільки на 4096 байтів.

`int a[4]{};` (порожні фігурні дужки) заповнює нулями. Без них — сміття.

Детально — [Lab 5](lab-05-many-of-one-thing.md).

## 7. Текст: `std::string`

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "ember";

    if (name == "ember") {              // рядки порівнюються через ==
        std::cout << name.size() << '\n';
    }

    std::string line;
    std::cout << "напиши щось: ";
    std::getline(std::cin, line);       // прочитати цілий рядок з клавіатури
    std::cout << "ти написав: " << line << '\n';
    return 0;
}
```

**Очікуй:** `5`, потім запит і відлуння того, що ви ввели.

`std::getline` повертає «неправду», якщо вводу більше немає (Ctrl-D) — у `main.cpp` скелета саме це завершує цикл.

Для розбору рядка на слова скелет використовує `std::istringstream`: кладемо в нього рядок, а далі `stream >> word` витягує слова по одному. Деталі дивіться в коді — переписувати це в Lab 1 не треба.

## 8. Тепер прочитайте `main.cpp`

```bash
less starter/src/main.cpp
```

Ви щойно побачили всі конструкції, які там є: `#include`, функція, `while (true)`,
`if`/`else if`, порівняння рядків, `std::cout`. Один незнайомий шматок —
`try`/`catch` у `parse_number`; це «якщо перетворення тексту в число не вдалось,
не падай». Приймається на віру до кінця курсу.

Мета — не зрозуміти кожен символ, а впізнати форму: **читаємо рядок → дивимось,
яке це слово → викликаємо потрібну функцію → повторюємо**.

## Коротко

| Треба | Пишемо |
|---|---|
| надрукувати | `std::cout << x << '\n';` |
| прочитати рядок | `std::getline(std::cin, line);` |
| розгалуження | `if (умова) { … } else { … }` |
| повторити N разів | `for (int i = 0; i < N; ++i) { … }` |
| повторити поки | `while (умова) { … }` |
| вийти з циклу | `break;` |
| іменований шматок коду | `int f(int x) { return …; }` |
| багато значень | `int a[4]{}; a[0] = 1;` |

Дві помилки, які ви точно зробите сьогодні: забута `;` і `=` замість `==`.
