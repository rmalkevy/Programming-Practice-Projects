## 1. Гра Коллатца

Візьміть число: парне — поділіть навпіл, непарне — помножте на 3 і додайте 1. Кажуть, будь-яке число колись дійде до 1, але з 1937 року ніхто цього не довів.

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int n = 6;
    int steps = 0;
    while (n != 1) {
        if (n % 2 == 0) {
            n = n / 2;
        } else {
            n = 3 * n + 1;
        }
        steps = steps + 1;
    }
    std::cout << steps << '\n';
}
```

**Вгадайте:** скільки кроків від 6 до 1?

**Зміни одне:** візьміть 7, потім 27.

**Що це означає:** `while` крутиться, поки умова істинна, і ніхто наперед не знає, скільки разів ([теорія §2](lab-04-the-shape-of-control.md#2-форми)).

## 2. Коротке замикання

`&&` і `||` не рахують праву частину, якщо відповідь уже відома з лівої.

```cpp
#include <cstdint>
#include <iostream>
bool check(int x) {
    std::cout << "check " << x << '\n';
    return x > 0;
}
int main() {
    if (check(0) && check(1)) {
        std::cout << "both\n";
    }
    if (check(2) || check(3)) {
        std::cout << "either\n";
    }
}
```

**Вгадайте:** усі рядки виводу по порядку.

**Зміни одне:** поміняйте місцями аргументи в першому `if`: `check(1) && check(0)`.

**Що це означає:** `A && B` не обчислює `B`, якщо `A` хибне; `A || B` — якщо `A` істинне ([теорія §1](lab-04-the-shape-of-control.md#1-порівняння-дають-булеві-значення-але-в-c-істинним-буває-й-число)).

## 3. switch, що провалюється

Без `break` виконання йде в наступний `case`. `[[fallthrough]]` лише каже компілятору, що ви зробили це навмисно.

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int level = 2;
    switch (level) {
    case 1:
        std::cout << "one\n";
        [[fallthrough]];
    case 2:
        std::cout << "two\n";
        [[fallthrough]];
    case 3:
        std::cout << "three\n";
        break;
    default:
        std::cout << "other\n";
    }
}
```

**Вгадайте:** що надрукує програма.

**Зміни одне:** візьміть `level = 1`, потім `level = 7`.

**Що це означає:** `switch` стрибає на свій `case` і йде вниз до `break` ([теорія §2](lab-04-the-shape-of-control.md#2-форми)).

## 4. Лічильник, що пам'ятає

Звичайна локальна змінна народжується заново з кожним викликом, а `static` — лише раз.

```cpp
#include <cstdint>
#include <iostream>
int counter() {
    static int calls = 0;
    calls = calls + 1;
    return calls;
}
int plain() {
    int calls = 0;
    calls = calls + 1;
    return calls;
}
int main() {
    for (int i = 0; i < 3; ++i) {
        std::cout << counter() << ' ' << plain() << '\n';
    }
}
```

**Вгадайте:** три рядки по два числа.

**Зміни одне:** подумайте без запуску: що надрукує четвертий виклик, якщо цикл зробити до `i < 4`?

**Що це означає:** локальна `static` ініціалізується один раз і живе до кінця програми ([теорія §4](lab-04-the-shape-of-control.md#4-область-видимості-час-життя-і-перегородка-між-ними)).

## 5. Три змінні на ім'я x

Внутрішній блок може завести своє `x` і сховати зовнішнє.

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int x = 1;
    std::cout << x << '\n';
    {
        int x = 2;
        std::cout << x << '\n';
        {
            x = 3;
            std::cout << x << '\n';
        }
    }
    std::cout << x << '\n';
}
```

**Вгадайте:** чотири числа по порядку.

**Зміни одне:** у рядку `int x = 2;` приберіть `int`.

**Що це означає:** затінення: внутрішнє ім'я ховає зовнішнє до кінця свого блока ([теорія §4](lab-04-the-shape-of-control.md#4-область-видимості-час-життя-і-перегородка-між-ними)).

## 6. Цикл, що не закінчиться

Скільки разів прокрутиться цикл до 256, якщо лічильник — один байт?

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int count = 0;
    for (std::uint8_t i = 0; i < 256; ++i) {
        count = count + 1;
    }
    std::cout << count << '\n';
}
```

**Вгадайте:** що надрукує програма? Потім зберіть.

**Зміни одне:** замініть заголовок циклу на `for (unsigned i = 10; i >= 0; --i)`. Хто тепер помітить проблему?

**Що це означає:** умова, яка завжди істинна, — це нескінченний цикл; компілятор інколи бачить це сам ([теорія §2](lab-04-the-shape-of-control.md#2-форми)).

## 7. Скільки разів довелося дивитись

Лінійний пошук іде підряд, поки не знайде. Але якщо масив відсортований, можна зупинитись раніше.

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int data[10] = {5, 8, 13, 21, 34, 42, 55, 89, 144, 233};
    int needle = 42;
    int looked = 0;
    int found = -1;
    for (int i = 0; i < 10; ++i) {
        looked = looked + 1;
        if (data[i] == needle) {
            found = i;
            break;
        }
    }
    std::cout << found << ' ' << looked << '\n';
}
```

**Вгадайте:** індекс і кількість переглянутих елементів.

**Зміни одне:** шукайте 40 замість 42. Потім додайте після першого `if` ще один: `if (data[i] > needle) { break; }` — і знову шукайте 40.

**Що це означає:** пошук — це цикл із виходом; у відсортованому масиві є ще один вихід ([теорія §3](lab-04-the-shape-of-control.md#3-лінійний-пошук--це-цикл-із-виходом)).
