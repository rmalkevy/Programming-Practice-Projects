## 1. Лічильник слів

Слово починається там, де після пробілу з'являється щось інше. Це найпростіший сканер.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    char text[] = "  hello   world  ";
    int words = 0;
    bool inside = false;
    for (int i = 0; text[i] != '\0'; ++i) {
        if (text[i] == ' ') {
            inside = false;
        } else if (!inside) {
            inside = true;
            words = words + 1;
        }
    }
    std::cout << words << '\n';
}
```

**Вгадайте:** скільки слів?

**Зміни одне:** візьміть текст `"one,two three"`.

### Напишіть самі

Напишіть лічильник слів, у якого роздільниками є пробіл, кома і табуляція (`'\t'`).

Для `"one,two three"` і `"  a,,b "` має надрукуватись: `3 2`

**Що це означає:** сканер пам'ятає один біт стану: «я всередині слова чи ні» ([теорія §1](lab-08-give-it-a-language.md#1-символи--це-ще-не-токени)).

## 2. Калькулятор на один рядок

Розібрати `12+34` символ за символом: число, знак, число.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    char expr[] = "12+34";
    int i = 0;
    int left = 0;
    while (expr[i] >= '0' && expr[i] <= '9') {
        left = left * 10 + (expr[i] - '0');
        i = i + 1;
    }
    char op = expr[i];
    i = i + 1;
    int right = 0;
    while (expr[i] >= '0' && expr[i] <= '9') {
        right = right * 10 + (expr[i] - '0');
        i = i + 1;
    }
    int result = (op == '+') ? left + right : (op == '-') ? left - right : left * right;
    std::cout << left << ' ' << op << ' ' << right << " = " << result << '\n';
}
```

**Вгадайте:** рядок виводу.

**Зміни одне:** візьміть `"10-20"`, потім `"7*6x"`.

### Напишіть самі

Навчіть калькулятор відмовляти. Після другого числа рядок має закінчитись; якщо ні — надрукуйте `error at N`, де N — позиція першого зайвого символу (з нуля).

Для `"12+34"` і `"7*6x"` має надрукуватись:

```txt
46
error at 3
```

**Що це означає:** число — це цифри підряд, а «що це таке» вирішує перший символ ([теорія §1](lab-08-give-it-a-language.md#1-символи--це-ще-не-токени)).

## 3. Правильне шістнадцяткове число?

Саме це робить `number()` у вашому лексері: вирішує, число це чи помилка.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
bool is_hex_digit(char c) {
    return (c >= '0' && c <= '9') || (c >= 'a' && c <= 'f') || (c >= 'A' && c <= 'F');
}
bool valid_hex(const char* s) {
    if (s[0] != '0' || s[1] != 'x') {
        return false;
    }
    int digits = 0;
    for (int i = 2; s[i] != '\0'; ++i) {
        if (!is_hex_digit(s[i])) {
            return false;
        }
        digits = digits + 1;
    }
    return digits > 0;
}
int main() {
    const char* tests[] = {"0x41", "0xGG", "0x", "41", "0xff"};
    for (int i = 0; i < 5; ++i) {
        std::cout << tests[i] << (valid_hex(tests[i]) ? " так" : " ні") << '\n';
    }
}
```

**Вгадайте:** для кожного з п'яти рядків — «так» чи «ні».

**Зміни одне:** останній рядок функції замініть на `return true;`.

### Напишіть самі

Мало сказати «так» — треба ще й порахувати. Напишіть `int hex_value(const char* s)` для правильного рядка `0x…`: кожна цифра множить результат на 16 і додає своє значення.

Для `"0x41"`, `"0xff"` і `"0x1A2"` має надрукуватись: `65 255 418`

**Що це означає:** зіпсоване число — це помилка, а не тихий нуль ([теорія §1](lab-08-give-it-a-language.md#1-символи--це-ще-не-токени)).

## 4. Список, що росте з голови

Кожен новий вузол стає першим і вказує на попередню голову.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
struct Node {
    int value;
    Node* next;
};
int main() {
    Node* head = nullptr;
    for (int v = 1; v <= 3; ++v) {
        head = new Node{v, head};
    }
    for (Node* n = head; n != nullptr; n = n->next) {
        std::cout << n->value << ' ';
    }
    std::cout << '\n';
    while (head != nullptr) {
        Node* next = head->next;
        delete head;
        head = next;
    }
}
```

**Вгадайте:** у якому порядку надрукуються числа?

**Зміни одне:** подумайте: що треба змінити, щоб числа вийшли `1 2 3`?

### Напишіть самі

Напишіть список, що росте з **хвоста**: тримайте окремий вказівник `tail` на останній вузол. Надрукуйте числа і довжину списку, а потім звільніть усі вузли.

Для 1, 2, 3 має надрукуватись:

```txt
1 2 3
3
```

**Що це означає:** вузли з'єднані вказівниками, і порядок залежить від того, куди додаєте ([теорія §3](lab-08-give-it-a-language.md#3-звязні-списки-коли-довжину-не-оголошують-а-зясовують)).

## 5. Контрольна сума GPS

GPS-приймач шле рядки на кшталт цього. Після `*` стоїть контрольна сума — XOR усіх символів між `$` і `*`.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    const char* sentence = "$GPGGA,123519,4807.038,N,01131.000,E,1,08,0.9,545.4,M,46.9,M,,*47";
    int sum = 0;
    int i = 1;
    while (sentence[i] != '*') {
        sum = sum ^ sentence[i];
        i = i + 1;
    }
    std::cout << std::hex << sum << '\n';
}
```

**Вгадайте:** чи збіжиться надруковане число з тим, що після `*`?

**Зміни одне:** змініть одну цифру: `4807.038` → `4807.039`.

### Напишіть самі

Напишіть `bool check_nmea(const char* s)`, яка сама рахує контрольну суму й порівнює її з двома шістнадцятковими цифрами після `*`.

Для рядка з коду вище і для того самого рядка з `4807.039` має надрукуватись: `1 0`

**Що це означає:** розбір рядка — це робота сканера, а контрольна сума ловить зіпсований рядок ([теорія §1](lab-08-give-it-a-language.md#1-символи--це-ще-не-токени)). Де це — [у залізі](HARDWARE.md#lab-8--дайте-їй-мову).

## 6. Токени руками

Маленький лексер: цифри — число, літера — ідентифікатор, решта — пунктуація.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    char line[] = "x=12+y";
    for (int i = 0; line[i] != '\0'; ) {
        char c = line[i];
        if (c >= '0' && c <= '9') {
            std::cout << "Number(";
            while (line[i] >= '0' && line[i] <= '9') {
                std::cout << line[i];
                i = i + 1;
            }
            std::cout << ") ";
        } else if (c >= 'a' && c <= 'z') {
            std::cout << "Ident(" << c << ") ";
            i = i + 1;
        } else {
            std::cout << "Punct(" << c << ") ";
            i = i + 1;
        }
    }
    std::cout << '\n';
}
```

**Вгадайте:** список токенів.

**Зміни одне:** візьміть рядок `"ab=7"`.

### Напишіть самі

Виправте лексер: ідентифікатор має з'їдати **всі** літери підряд, так само як число з'їдає всі цифри.

Для рядків `"ab=7"` і `"count=12+x"` має надрукуватись:

```txt
Ident(ab) Punct(=) Number(7)
Ident(count) Punct(=) Number(12) Punct(+) Ident(x)
```

**Що це означає:** лексер класифікує наступну лексему за першим символом ([теорія §1](lab-08-give-it-a-language.md#1-символи--це-ще-не-токени)).
