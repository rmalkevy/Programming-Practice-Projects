## 1. Відстань між сусідами

Сусідні елементи масиву лежать у пам'яті впритул. Але «відстань» між ними залежить від того, чим міряти.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int a[3] = {10, 20, 30};
    std::cout << (&a[1] - &a[0]) << '\n';
    std::cout << ((char*)&a[1] - (char*)&a[0]) << '\n';
    std::cout << (&a[2] - &a[0]) << '\n';
}
```

**Вгадайте:** три числа.

**Зміни одне:** замініть `int a[3]` на `double a[3]`.

### Напишіть самі

Напишіть `const int* max_ptr(const int* a, int n)`, яка повертає **вказівник** на перший найбільший елемент. Потім надрукуйте значення за ним і його індекс як `p - a`.

Для масиву `{3, 9, 2, 9, 5}` має надрукуватись: `9 1`

**Що це означає:** різниця вказівників рахує елементи, а різниця `char*` — байти ([теорія §2](lab-03-addresses-not-names.md#2-у-вказівника-є-тип-щоб--і--знали-розмір)).

## 2. Обмін, який не працює

Класика: функція, яка мала поміняти змінні місцями, а нічого не змінила.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
void swap_copy(int x, int y) {
    int t = x;
    x = y;
    y = t;
}
void swap_ptr(int* x, int* y) {
    int t = *x;
    *x = *y;
    *y = t;
}
int main() {
    int a = 1, b = 2;
    swap_copy(a, b);
    std::cout << a << ' ' << b << '\n';
    swap_ptr(&a, &b);
    std::cout << a << ' ' << b << '\n';
}
```

**Вгадайте:** що надрукують обидва рядки.

**Зміни одне:** після `swap_ptr(&a, &b);` допишіть `swap_ptr(&a, &a);`. Що буде?

### Напишіть самі

Напишіть `void sort3(int* a, int* b, int* c)`, яка впорядковує три змінні за зростанням. Скористайтесь `swap_ptr` з коду вище.

Для `(3, 1, 2)` і `(9, 9, 1)` має надрукуватись:

```txt
1 2 3
1 9 9
```

**Що це означає:** копія живе у своєму кадрі, а вказівник веде до оригіналу ([теорія §1](lab-03-addresses-not-names.md#1-імена-живуть-у-компіляторі-адреси--у-машині)).

## 3. Крокуємо вказівником

Цикл по масиву можна написати без індексу — лише вказівником, який іде вперед.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int a[5] = {3, 1, 4, 1, 5};
    int* p = a;
    int sum = 0;
    for (int i = 0; i < 5; ++i) {
        sum = sum + *p;
        p = p + 1;
    }
    std::cout << sum << '\n';
    std::cout << (p - a) << '\n';
}
```

**Вгадайте:** суму і те, на скільки елементів пішов `p`.

**Зміни одне:** почніть з `int* p = a + 1;` і пройдіть лише 4 кроки (`i < 4`).

### Напишіть самі

Напишіть `void reverse(int* a, int n)` двома вказівниками, які йдуть назустріч: один з початку, другий з кінця.

Для `{1, 2, 3, 4, 5}` має надрукуватись: `5 4 3 2 1`

**Що це означає:** `p + 1` — наступний елемент, а `p - a` — скільки елементів пройдено ([теорія §2](lab-03-addresses-not-names.md#2-у-вказівника-є-тип-щоб--і--знали-розмір)).

## 4. Порядок байтів вашого ноутбука

Протокол MAVLink, яким спілкуються дрони, записує числа молодшим байтом уперед, а мережеві протоколи — навпаки. Яким уперед пише ваш ноутбук?

### Передбачте

```cpp
#include <cstdint>
#include <cstring>
#include <iostream>
int main() {
    std::uint32_t value = 0x12345678;
    unsigned char bytes[4];
    std::memcpy(bytes, &value, 4);
    std::cout << std::hex;
    for (int i = 0; i < 4; ++i) {
        std::cout << (int)bytes[i] << ' ';
    }
    std::cout << '\n';
}
```

**Вгадайте:** чотири байти в тому порядку, у якому вони лежать у пам'яті.

**Зміни одне:** замініть число на `0xFF`.

### Напишіть самі

Приймач отримав чотири байти з радіо. Напишіть `std::uint32_t read_le(const unsigned char* b)`, яка складає з них число молодшим байтом уперед, і `read_be` — старшим уперед. Надрукуйте обидва через `std::hex`.

Для байтів `{0x78, 0x56, 0x34, 0x12}` має надрукуватись: `12345678 78563412`

**Що це означає:** чесний спосіб подивитись на байти — `std::memcpy` ([теорія §3](lab-03-addresses-not-names.md#3-void--це-адреса-без-типу)); ваш ноутбук кладе молодший байт першим.

## 5. Як виглядає 1.0f у бітах

Число з рухомою комою — це знак, порядок і мантиса в одних 32 бітах. Датчики часто передають саме їх.

### Передбачте

```cpp
#include <cstdint>
#include <cstring>
#include <iostream>
int main() {
    float f = 1.0f;
    std::uint32_t bits = 0;
    std::memcpy(&bits, &f, sizeof(bits));
    std::cout << std::hex << bits << '\n';
    f = -1.0f;
    std::memcpy(&bits, &f, sizeof(bits));
    std::cout << bits << '\n';
}
```

**Вгадайте:** чим відрізнятимуться два числа.

**Зміни одне:** замість `-1.0f` візьміть `2.0f`.

### Напишіть самі

У 32 бітах `float` старший біт — знак, наступні вісім — порядок. Напишіть програму, яка для числа дістає ці два поля з бітів зсувом і маскою.

Для `-2.5f` і `1.0f` має надрукуватись:

```txt
1 128
0 127
```

**Що це означає:** `memcpy` у `uint32_t` — визначений спосіб побачити біти `float`, а приведення `float*` до `int*` — ні ([теорія §3](lab-03-addresses-not-names.md#3-void--це-адреса-без-типу)).

## 6. Один крок за край

Вказівник на останній елемент — законно. Ще один крок — і ви читаєте чужу пам'ять.

### Передбачте

```cpp
#include <cstdint>
#include <iostream>
int main() {
    int a[3] = {1, 2, 3};
    int* p = a + 2;
    std::cout << *p << '\n';
    p = p + 1;
    std::cout << *p << '\n';
}
```

**Вгадайте:** що надрукує програма і хто зупинить другий рядок.

**Зміни одне:** замініть перші три рядки `main` на `int* p = nullptr;` і `(void)a;`.

### Напишіть самі

Вказівник «одразу за кінцем» масиву створювати можна, розіменовувати — ні. Саме так у C++ задають діапазон `[begin, end)`. Напишіть `int sum(const int* begin, const int* end)`, яка додає, поки `begin != end`.

Для `sum(a, a + 3)` при `a = {1, 2, 3}` і для порожнього `sum(a, a)` має надрукуватись: `6 0`

**Що це означає:** санітайзер ловить вихід за межу там, де «ну, надрукувало щось» мовчить ([теорія §1](lab-03-addresses-not-names.md#1-імена-живуть-у-компіляторі-адреси--у-машині)).
